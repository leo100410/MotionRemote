Volume Down now maps to **B** in every sport. Press and hold it to hold B; release it to release B. Volume Up keeps its existing sport-specific or manually selected mapping.

The two volume buttons and on-screen buttons have independent hold states, including when both volume buttons map to B. Switching camera mode releases both hardware inputs.

### Downloads

- **MotionRemote-1.9.ipa** — unsigned iPhone app; sign with your existing signing tool or build in Xcode.
- **MotionRemote-1.9-project.tar.gz** — application source, controller profiles, Dolphin patch and documentation.
- **SHA256SUMS-1.9.txt** — checksums for these files.

**No Dolphin update is required.** Continue using [Dolphin MotionRemote 1.8](https://github.com/leo100410/MotionRemote/releases/tag/v1.8) and the existing controller profiles.

The release build and volume mapping/hold-state checks pass. Physical volume-button behaviour still depends on camera permission and the existing foreground capture interaction.
